# Design

## Basic Layout

下吸引方式の3分割構造にします。

1. 上部リングで15cmうらごし付属の金属リングを浅く受ける
2. 整流チャンバーでザル全体から均一に吸う
3. 下部ベースに120mmファン、側面排気、電装部をまとめる

## Airflow

- 豆の上から外気を取り込む
- ザルのメッシュを通して下方向へ吸引する
- ザル底面のメッシュと空洞チャンバーで吸引ムラを抑える
- 上面のファン取付プレートで吸気側と排気側を分ける
- ファンを通過した空気を下部の排気チャンバーへ送り、側面へ排気する

排気口の合計面積は、ファン有効開口面積の1.2倍以上を目標にします。

側面排気口は排気チャンバー側にだけ設けます。整流チャンバー側に横穴があると、豆とザルを通らない空気のショートカットが起きて冷却効率が下がるためです。

## Cleaning

- ザル固定リングは取り外し可能にする
- 上部リングとTPUガスケットは全周を閉じ、内径側の空気漏れを抑える
- 整流リブは設けず、掃除しやすい空洞チャンバーにする
- ファンへチャフや微粉が落ちにくい構造にする
- 電装部と豆の流路を分ける
- 電装室にはPWMコントローラとDCジャックの仮固定ボス、レール、前面開口を設ける
- ベース底面は塞がず、外周フレームを残して掃除とファン交換をしやすくする

## Printability

- PETGを想定する
- 基本壁厚は2.4mmから3.2mm
- 長い橋渡しを避ける
- ネジ穴、嵌合部はクリアランスを持たせる
- 大きな一体造形ではなく、修正しやすい分割部品にする
