| Item                   | Value | Notes                            |
| ---------------------- | ----- | -------------------------------- |
| 外径                   | 163mm | 上端の最大径                     |
| 内径                   | 157mm | ザルがリングへ落ち込む位置       |
| 縁の高さ               | TBD   | 段付きリップ設計に使用           |
| 底面メッシュ有効径     | 141mm | 吸引範囲に使用                   |
| 全高                   | 55mm  | 収納と干渉確認                   |
| 底面形状               | 平面  | 平面、丸み、足の有無             |
| 付属金属リング外径     | TBD   | `top_ring` の受けポケットに使用  |
| 横の引っ掛けリング寸法 | TBD   | 干渉逃げの幅、奥行き、高さに使用 |
| TPUガスケット厚み      | 1.2mm | 初期設計値。ザルの座り具合で調整 |

## Fit Notes

- `top_ring` はザル付属の金属リングを浅いポケットで受ける
- 横の引っ掛けリングが干渉しないよう、逃げ切り欠きを設ける
- ザルの取り外しやすさを確認する
- 熱い豆が樹脂に直接触れないか確認する
