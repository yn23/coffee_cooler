# コーヒークーラー
以下のような部品で3Dプリンタで本体を作って焙煎したコーヒー豆を冷やすための機器を自作したい。


## 構成
| #   | 商品名                                                  | 用途                                   | URL                                                                      | 備考                            |
| :-- | ------------------------------------------------------- | -------------------------------------- | ------------------------------------------------------------------------ | ------------------------------- |
| 1   | パール金属 EEスイーツ ステンレス製 うらごし 15cm D-4730 | 豆を冷やすための受け皿                 | -                                                                       | 外径163mm、高さ55mm             |
| 2   | beyourchoi PWM コントローラ モーターコントローラー      | 豆を冷やすためのファン用コントローラー | https://www.amazon.co.jp/dp/B0CX55SRYM?ref=ppx_yo2ov_dt_b_fed_asin_title | -                               |
| 3   | DC電源ジャック ソケット 5.5mm x 2.1mm                | 12V入力用の電源ソケット               | -                                                                        | パネルマウント前提              |
| 4   | 120mm PWMファン                                         | 豆を冷却するためのファン               | 候補は docs/parts.md 参照                                                | 12V、4-pin PWM、厚み25mm想定    |
| 5   | 本体                                                    | 上記1～4の部品を組み込むための筐体     | -                                                                        | 3Dプリンターで自作のためURLなし |

## 要件
 - ファンは120mm PWMファン
- DC電源ジャックから12V給電
 - PWM速度調整あり
 - PWMコントローラーで電源ON/OFF
 - 3Dプリンタで本体作成
 - PETG想定
 - 下吸引方式
 - 側面排気
 - 分解掃除しやすい構造
 - OpenSCAD向け
 - STL化しやすい構造
 - 120mmファン固定穴対応
 - ザル固定リングあり
 - 空気が均一に流れるよう整流空間を設けたい

## 使用機材
 - 3Dprinter : Bambu Lab A1 mini
